# Stage A: Background-Aware Sparse PSF Unmixing

Stage A is trained independently after the G0 image-only baseline. It accepts
only a normalized infrared image `I` and returns five full-resolution maps:

- `B`: spatially varying background;
- `S`: non-negative sparse source/centroid activation;
- `T_psf`: explicit PSF response generated by applying a constrained,
  spatially mixed anisotropic Gaussian kernel bank to `S`;
- `R`: signed non-PSF target-shape correction;
- `U`: normalized reconstruction-error uncertainty.

The reconstruction contract is `I ~= B + T_psf + R`. Masks are used only to
construct weak training targets and evaluation diagnostics; they are not model
inputs.

The v5.2a signed-R repair keeps the scale-separated v5 dual-source objective.
Public `U` is the directly supervised normalized reconstruction-error map;
its feature input is detached so U supervision cannot reshape the shared
decomposition backbone. Each weak target is split into an energy-matched,
moment-fitted anisotropic Gaussian teacher and a signed shape correction.
`T_psf`, `R`, and their sum are supervised against those fixed roles.

## Experiment scope

This is a method-exploration run with seed 42. It measures checkpoint,
perturbation, and cross-domain stability, but does not establish stability
across random initializations. Passing Stage A means that its decomposition is
interpretable enough to freeze for G1--G5. It does not mean that A has already
improved segmentation.

Only the original 800-image IRSTD-1K training split is used for training and
validation: 720 train and 80 deterministic validation samples. The 201-image
test split never selects a checkpoint.

SIRST4 is reported as two subsets because its 201 `XDU*` test images duplicate
the IRSTD-1K test set. `sirst4_non_xdu` is the cleaner cross-domain result.

## Remote environment

Use a Python environment where the CUDA build of PyTorch is already installed.
Do not install a CPU-only PyTorch wheel over it.

```bash
cd /path/to/new_model_v3
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.get_device_name(0))"
python -m pip install -r requirements-a.txt
```

The expected device is one NVIDIA RTX 4090 with 24 GB memory.

## One consolidated preflight and GPU smoke run

The smoke directory is timestamped to prevent overwriting an earlier run.

```bash
cd /path/to/new_model_v3
set -euo pipefail

python -m pytest -q --ignore=tests/test_gaussamr_gate_b.py tests
python -m compileall -q irstd_a train_a.py eval_a.py visualize_a.py configs/a_psf_irstd1k.py

SMOKE_DIR="runs/a_psf/debug/smoke_seed42_$(date +%Y%m%d_%H%M%S)"
python train_a.py \
  --config configs/a_psf_irstd1k.py \
  --run-dir "$SMOKE_DIR" \
  --device cuda --debug --limit-train 8 --limit-val 4 --epochs 2

python eval_a.py \
  --checkpoint "$SMOKE_DIR/a_best.pt" \
  --run-dir "$SMOKE_DIR" \
  --datasets irstd1k sirst_uavb sirst4 \
  --limit 4 --probe-count 2 --device cuda

python visualize_a.py \
  --checkpoint "$SMOKE_DIR/a_best.pt" \
  --metrics "$SMOKE_DIR/per_image_metrics.csv" \
  --output-dir "$SMOKE_DIR/visualizations" \
  --max-panels 8 --device cuda

echo "SMOKE_DIR=$SMOKE_DIR"
tail -n 20 "$SMOKE_DIR/log.txt"
```

All tests must pass; both training epochs must remain finite; peak allocated
memory must remain below 24 GB; and the smoke directory must contain best/last
checkpoints, metrics, stability JSON, CSV, component panels, and a PSF sheet.

## Formal exploratory training

Run only after the consolidated smoke output and visual panels have been
reviewed. The console log is a sibling of the run directory so `train_a.py`
can enforce an initially empty formal directory.

```bash
cd /path/to/new_model_v3
set -euo pipefail
mkdir -p runs/a_psf
RUN_DIR="runs/a_psf/irstd1k_seed42_v5_2a_signed_r"

python train_a.py \
  --config configs/a_psf_irstd1k.py \
  --run-dir "$RUN_DIR" \
  --device cuda --seed 42 2>&1 | tee "${RUN_DIR}_console.log"
```

If interrupted, resume without creating a new split:

```bash
python train_a.py \
  --config configs/a_psf_irstd1k.py \
  --run-dir runs/a_psf/irstd1k_seed42_v5_2a_signed_r \
  --resume runs/a_psf/irstd1k_seed42_v5_2a_signed_r/a_last.pt \
  --device cuda --seed 42 2>&1 | tee -a runs/a_psf/irstd1k_seed42_v5_2a_signed_r_console.log
```

## v5.1 three-dataset generalization matrix

`run_a_v5_1_matrix.sh` reproduces the historical `v5.1-ur` objective, trains
one model on each official training split, and evaluates every best checkpoint
on IRSTD-1K, SIRST-UAVB, and SIRST4. On a Linux CUDA host, run:

```bash
bash run_a_v5_1_matrix.sh
```

The same command resumes any directory containing a compatible `a_last.pt` and
skips a training run only when its completion marker and best checkpoint both
validate. It expects split counts of 800/201 for IRSTD-1K, 2400/600 for
SIRST-UAVB, and 2285/1067 for SIRST4. It never installs or replaces PyTorch.

For a wiring-only smoke run:

```bash
SMOKE=1 DEVICE=cpu NUM_WORKERS=0 LIMIT_TRAIN=4 LIMIT_VAL=2 EPOCHS=1 \
RUN_ROOT=runs/a_v5_1_matrix/debug/smoke bash run_a_v5_1_matrix.sh
```

Formal artifacts are isolated below `runs/a_v5_1_matrix/`. The final products
include three best checkpoints, per-source metrics, `matrix_summary.json`,
`matrix_summary.csv`, a combined per-image CSV, `matrix_manifest.sha256`, and
`runs/a_v5_1_matrix.tar.gz`. SIRST4 is reported as the full official test set,
its duplicated 201-image XDU subset, and the clean 866-image non-XDU subset.

Stage A is a physical decomposition model rather than a segmentation model, so
this experiment reports target recovery, background leakage, reconstruction,
uncertainty, stability, and runtime diagnostics—not segmentation IoU. The
v5.1-to-G0 segmentation experiment remains separate and is not implemented by
this runner.

## Result interpretation

The main quantitative artifacts are `metrics.json`, `stability.json`, and
`per_image_metrics.csv`. Review them together with every selected nine-panel
image:

`I | Y | B | S | T_psf | R | U | reconstruction | absolute error`.

The exploratory gate expects, on IRSTD-1K test:

- target-output energy precision at least 0.80;
- source false activation at most 0.20;
- median background target leakage at most 0.30;
- median signed-residual teacher NMAE at most 0.50;
- R improves over PSF-only reconstruction on at least 5% of target images;
- uncertainty/error Spearman correlation at least 0.30;
- median component correlation at least 0.90 for flips/intensity and 0.80 for
  noise;
- no dense-source, residual-copy, background-copy, or zero-PSF collapse.

Cross-domain target recovery may be poor during exploration, but numerical or
component-energy collapse fails Stage A. Visual evidence overrides a misleading
aggregate: if `B` visibly retains targets, `R` copies the image, or `S` follows
cloud edges, revise A before starting G1--G5.
